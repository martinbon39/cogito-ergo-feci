# Provenance

This repository is a snapshot of the work, published as a single commit. The full development history is in the
archived, read-only repository [martinbon39/ComputerUseHackaton](https://github.com/martinbon39/ComputerUseHackaton). Every commit hash of the project's own history
cited here, in the paper's source comments or in a data file refers to that repository; hashes of other repositories
are listed at the end. That history records when each pre-registration, protocol and amendment was committed, and
when analysis code was committed relative to the results it analyses.

How far this goes:
- Git commit times are written by whoever commits. They are not an independent timestamp.
- A commit time shows that a file existed at that time. Whether it came before the data it judges is stated in the
  file itself and in the paper's appendix "How the research was run"; amendments say what had been seen when they
  were written.
- Pre-registration, protocol and amendment files are byte-identical to their last version in the development
  repository (commit [`26565da`](https://github.com/martinbon39/ComputerUseHackaton/commit/26565dace87c55db3f1ce69cfe4dead6ba1472a6)). Data files (JSON, CSV,
  arrays, images, logs) are byte-identical. Reports, scripts and docs differ in updated paths, in links to files that were never committed (now marked "not in
  the repository"), in scrubbed signed URLs and one third-party API key; no number changed. The paper gained an
  acknowledgements section, sentences on the repositories (`intro.tex`, `repro.tex`) and repository names in source
  comments (`guard.tex`, `discussion.tex`); its PDFs and figure PDFs were rebuilt.

Times are git committer times in UTC. Paths are those of this repository; [REPO_MAP.md](REPO_MAP.md) gives the former
ones.
