## Question and preregistration

Can a model that reads correct evidence lose its binding to that evidence as its own reasoning updates recurrent memory? H1 tests this dynamic directly; H2, prepared separately before any H2 forward, restores the conditional memory-gate matrices of Holo's Qwen3.5-4B parent. Neither is evidence that the gates caused the original failure.

All required historical reports were read before choosing interventions. The failed global A_log perturbation in astra-mit1 was also checked, so it is not repeated here. Protocols, corpus/seed freeze, source hashes, and the forward ledger are in PROTOCOL.md, H2_PROTOCOL.md, FREEZE.json, and budget.jsonl. H1 uses 4 seeded generations with the existing harness settings (T=0.8, top_p=0.9, top_k=20, thinking enabled, 3072-token cap, JSON grammar), plus 3 deterministic text controls. ## H1: preserve memory while generating

For the nine late DeltaNet layers 20,21,22,24,25,26,28,29,30, modify only generated-token memory updates:

    S_t = alpha S_prev + beta k (v - alpha S_prev^T k)^T
    alpha' = alpha^rho ; beta' = rho beta

Prompt processing retains the original dynamics. rho=1 is baseline, rho=0.25 slows memory evolution, rho=0 freezes it. These are diagnostic inference hooks, not static weight edits or submitted candidates. The implementation leaves source parameters unchanged, disables prefix caching, and masks by actual vLLM decode metadata. An independent CPU verifier checked the gate algebra, BF16 approximation, mixed prefill/decode masking, and fused [b,a] layout (VERIFY_GATE_CPU.md and evidence.json).
