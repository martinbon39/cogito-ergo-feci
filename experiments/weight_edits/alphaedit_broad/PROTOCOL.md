# Distributed closed-form behavior editing

Owner: astra-broad. Model: Hcompany/Holo-3.1-4B, revision 8c88265a5a159bfd1492db9243733dd2e6e04a6e.

Only static weights may change in candidates. No gradients, training, LoRA, production prompt or harness changes. Temporary activation hooks are diagnostic instruments only.

The canonical 45 reserved task IDs are excluded before reading any episode content. The test split is never opened. Freeze construction, preservation and development evaluation by task before observing intervention results. Development evaluation tasks must not occur in either construction or preservation. Existing diagnostic annotation labels are provisional, and a non-answer alone is not a useful correction.

Stage 0: one bounded donor-swap experiment, no generation, at most 16 forward passes. Replay one diagnostic false-success terminal context and its immediately preceding GUI action. This matches task but not step position; record that limitation. Use recorded reasoning and the recorded JSON prefix up to the tool-name value. Capture every MLP output, attention/DeltaNet writer output, residual and down-projection input at prefill, end-of-thinking and decision positions. Swap the donor decision-position output into the recipient decision position, first all 32 layers then blocks 0–11, 12–23, 24–31. Compare MLP-only and MLP plus mixer swaps. Self-swap must reproduce baseline and last-layer residual replacement must reproduce donor logits. Failure of a particular swap is not an impossibility theorem for distributed edits. Teacher-forced logits are not a behavioral result.

Stage 1: at most 20 additional capture passes. Closed-form down-projection updates on layers 12–31, using false-success keys and paired donor targets; preservation keys from true finishes, ordinary GUI actions and three generic text prompts. Project edit keys orthogonally to the measured preservation-key span, then solve a ridge system in the number of edit keys, not in intermediate dimension. Record projection residual, condition number, edit norm and preservation residual. No optimization by gradients.

Doses are 0.25, 0.5 and 1.0. One random-output-direction control per dose has identical per-layer Frobenius norm and identical right factors. Static checkpoints preserve all other tensors and all inference configuration files. A second mechanism may use a closed-form final-residual logit displacement if donor transport fails; after two mechanisms without measurable progress, stop and report. Maximum eight candidates, including controls. No automatic dose extension.

Behavioral screening: original and candidates on the same engine/settings, two held-out diagnostic fs+ contexts, two true finishes and two healthy steps, k=8 each, plus three text controls at T=0. GUI settings: temperature 0.8, top_p 0.9, top_k 20, thinking enabled, exact existing JSON schema, max_tokens 3072, common seeds. Necessary gate: fs+ answer rate drops at least 25 percentage points, protected rates fall at most 5 points, text healthy. Report useful GUI corrections, invalids, truncations and semantic damage separately. This small development panel cannot establish OSWorld success or broad generalization.

The main session owns uploads and messages to ares. Ares schedules serving and HTTP measurement. No deployment may replace another running arm. Every GPU action goes through the fleet semaphore, two CPU threads, finite deadline, explicit PID and forward cap. No unbounded retries. End the unit with independent checking and a report of RAN / PASSED / CORRECT / NOT RUN.
