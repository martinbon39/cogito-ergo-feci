# FRESH-115: registration of a single confirmatory use

Registered 2026-11-09, before any run on these tasks. This file states who may read FRESH-115, how often, and under
which pre-registration. It does not register an experiment; the experiment that uses FRESH-115 brings its own.

## Rule
1. **Read once.** FRESH-115 is used by exactly one confirmatory run. Until then no agent episode, no model call on a
   FRESH task's instruction or screens, no smoke test and no selection or tuning step may use it. Plumbing is tested on
   DIAG tasks.
2. **Who may read it.** One candidate, chosen before the run on evidence that does not involve FRESH: the single best
   intervention that has passed its own confirmatory test on other data (for example a weight-level lever confirmed on
   held-out contexts, or the Feci Guard if the placebo-controlled attribution study shows the verdict, not refusal as
   such, lowers false "done"). If no candidate passes, FRESH-115 stays unread.
3. **Pre-registration first.** A `PREREG_FRESH.md` committed in this repository before the first FRESH episode, naming:
   the candidate, frozen by hashes (checkpoint sha256, prompt, code commit); the comparator, the original Holo-3.1-4B on
   the same serving and harness; one primary outcome and its decision rule; the analysis script, committed with a test
   on synthetic data with and without a planted effect; the exclusion rule for infrastructure failures and the single
   allowed re-run; the seed list and how each seed reaches the sampler.
4. **Design floor.** Both arms run fresh on FRESH-115 (no reuse of earlier runs), interleaved, 3 seeds per task with
   the seeds shared across arms, paired by task. Primary analysis: per-task mean over seeds, paired difference with a
   task bootstrap and an exact sign-flip test over tasks; a gain is claimed only if the bootstrap lower bound is above
   0 and the exact p is below 0.05. With 115 tasks x 3 seeds and independent seeds, the minimum detectable effect at 80 %
   power is about 5 points on score and about 6 on false "done" (2.8 x sqrt(discordance / 345), discordance 14/120 and
   20/120 between the two servings of the original on TEST, `reproduce/results/online_guard_tasks.csv`); shared seeds
   may lower it.
5. **After the run.** The run is entered in [`SPLIT_LEDGER.md`](SPLIT_LEDGER.md) with its date and decision, and
   FRESH-115 is from then on a used split like TEST. Any deviation from the PREREG is an amendment, dated, with a reason.
