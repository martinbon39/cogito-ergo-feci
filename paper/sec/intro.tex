\section{Introduction}

Computer-use agents run a closed loop. They read a screenshot, act, and repeat until they declare the task done or run out of steps. A recurring way to fail is to declare it done when it is not: the agent announces success, the episode ends, and the environment's checker returns zero \citep{legacyworld2026}. Figure~\ref{fig:teaser}a shows one such episode. The agent writes that it cannot finish without a password, then, instead of finishing or declaring the task blocked, calls \texttt{answer}: the installation ``has been initiated successfully'', and the user should enter the password to complete it. The answer ends the episode with nothing installed. Users of Holo report the same failure in deployment. In an open issue on H Company's desktop client, screen capture fails while a Windows elevation prompt is shown (39 times in a row over 19 seconds in the author's standalone probe); in the agent run, the last steps log the capture error, the agent keeps typing and switching windows blind, then reports the task completed, while the author verified that nothing was done and an unsaved document was in the foreground \citep{holodesktop2026issue15}. In the author's words, ``The agent has no `I cannot see' state.'' % source: https://github.com/hcompai/holo-desktop-cli/issues/15 (read with gh, 2026-11-07); research_notes/Problèmes frontier de H/h_user_feedback.md item A.1


Interpretability offers a tempting repair. If a behaviour is mediated by one direction in the residual stream, projecting that direction out of every matrix that writes into the stream removes the behaviour, with no gradient step \citep{arditi2024refusal}. ``Weight-space programming'' recently removed a looping habit from a 0.8B language model by subtracting one direction from 64 \texttt{down\_proj} columns in two MLP layers (131{,}072 weights), with edits written by an LLM agent, and attributed the gain to removing an obstacle that hid an ability the model already had \citep{takehi2026wsp}. % source: BRIEF_neurochirurgie_holo_LOCAL.md section 0 (summary of the MIT post)
False success looks like the ideal target for this recipe. It is frequent (Fig.~\ref{fig:teaser}b) and it is a single discrete decision, the call to the \texttt{answer} tool, of the kind that single directions are known to steer \citep{wu2026toolcalling,chen2026toolrate}.

This paper is about the gap between finding such a direction and proving that it causes the behaviour. A probe that separates failing from healthy steps shows correlation, and its accuracy may reflect the probe more than the representation \citep{hewitt2019control}; causation needs an intervention and a behavioural measurement \citep{belinkov2021probing}. In GUI agents that gap is wide, because the obvious signals are confounded with the position in the episode and because agent outcomes are noisy enough that an untreated re-run looks like an effect.

\paragraph{Contributions.} We report only what we measured.
\begin{enumerate}
\item \textbf{A diagnosis of a real agent on real desktops} (\S\ref{sec:diag}). Holo-3.1-4B solves \oswNSuccess/\oswNScored{} tasks of a frozen OSWorld split. Of \oswNFail{} failures, \oswCatFalseSuccess{} are false successes, \oswCatStepLimit{} hit the step limit and \oswCatLoop{} loop; \oswCatOther{} is unclassified. Re-sampled, it still says ``done'' on most false completions (\pwOrigFspPct\%, against \pwOrigFsmPct\% on true ones) (\S\ref{sec:think}).
\item \textbf{A replay pipeline} (\S\ref{sec:replay}) from a vLLM-served agent to per-layer activations in \texttt{transformers}, which rebuilds each step's input, with a message-level check of the rebuilt chat and a token-level check of the processor; many episodes were replayed on their last three steps only, and some long ones were skipped for memory.
\item \textbf{An anti-confound protocol, motivated by three measured traps} (\S\ref{sec:traps}): position-confounded directions, regression to the mean between runs, and detection without causation. Each would have produced a false positive here.
\item \textbf{A causal record of every intervention we ran} (\S\ref{sec:causal-results}), as pre-registered pilot screens, with a layer-by-position causal map of the tool choice. None passes the gate, and the screens could find only large effects: the gate flags a fall to \gateMaxAnswers/8 false answers or fewer, and one of the two false-success screening contexts is an infeasible task, so the evidence on feasible false successes rests on a single context and a few samples per arm (Appendix~\ref{app:infeasible}). The tool call leans on the text the model has already written, and the edits that move it lower true completions too. On a strictly feasible cohort, a model merge shows no detectable selectivity, and the selectivity of a closed-form edit is not established either way. A detector of imminent completion beats position but does not separate false from true completions (\S\ref{sec:perceive}). No edited or prompted model arm run online beats the run-to-run difference of the original (\S\ref{sec:online}). We found no weight edit that passes; weight surgery of the kind tested has not shown that it can supply the missing check (\S\ref{sec:discussion}).
\item \textbf{An external verifier} (\S\ref{sec:guard}), Feci Guard, which uses Claude Sonnet (through the Claude Code CLI alias \texttt{sonnet}, version not pinned) to refuse an unsupported ``done'' and say what is missing. Offline, on \gbEpisodes{} episodes of the agent, it detects \gbClaudeDet\% of false successes and rejects \gbClaudeRej\% of true ones, where the agent judging itself is not distinguishable from chance. In a repair measure on replayed false successes, branches continued with the guard score 1 in \fgRepRepairedGuard{} of \fgRepBranches{} against \fgRepRepairedNog{} without it, \fgRepSpecific{} against 0 after a refusal, without statistical evidence; handing refused episodes to a stronger agent, Holo4-27B, scores 1 in \rbGuardSucc{} replayed branches against \rbCtrlSucc{} for that agent alone (\rbGuardAfterAction{} against \rbCtrlAfterAction{} after a new action; \rbPrimDiff{} points, bootstrap 95\% CI \rbPrimDiffCi), on \rbPrimEpisodes{} episodes only, where an exact test gives $p=\exRbPrimP$: not significant at the 5\% level. Online, on the \OgN{} \textsc{test} tasks, the guarded run's false ``done'' rate fell from \OgFdBase\% to \OgFdGuard\%, formally meeting its registered criterion, but about two thirds of the drop come from episodes in which the agent never answered and the guard never ran, so we do not attribute it to the guard; the score change is \OgScoreDiff{} (\OgScoreDiffCi).
\end{enumerate}
