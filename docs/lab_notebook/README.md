# Lab notebook

Raw working logs of the project, kept verbatim as provenance. The paper's appendix "How the research was run" condenses
them. They are mostly in French and were written while the work ran, so they use the repository layout of that time
(`holo-neurochir/...`, `jury_kit/...`, agent code names such as `astra-merge`); [`../REPO_MAP.md`](../REPO_MAP.md)
maps every old path to the current one.

| File | What |
|---|---|
| [`LOG.md`](LOG.md) | Orchestrator log (session `ares`), chronological |
| [`JOURNAL.md`](JOURNAL.md) | Research journal, chronological |
| [`BRIEF_neurochirurgie_holo_LOCAL.md`](BRIEF_neurochirurgie_holo_LOCAL.md) | The original research brief |
| [`HANDOFF.md`](HANDOFF.md) | Handover notes between sessions |

Commit hashes of the project's history in these logs refer to the development repository
[martinbon39/ComputerUseHackaton](https://github.com/martinbon39/ComputerUseHackaton) ([`../PROVENANCE.md`](../PROVENANCE.md)).
