# Round 2 protocol
Seeds 0–5 only for fit and selection. No new heldout contents before a2_freeze.json.
Primary effect D = mean(original mean_lp - edited mean_lp), raw recorded reply + EOS teacher-forced, nats/token. Healthy union = success OR loop- (deduplicated); also report each subgroup. Qualify if D_loop > 0 and D_loop >= 3 * max(0,D_union,D_loopminus,D_success). Rank qualifying candidates by largest D_loop, then fewer targeted weights. Old candidates remain eligible under this new criterion.
At most 18 new screen candidates in 3 rounds of <=6. Stop after two rounds without improvement of best qualifying D_loop (tolerance 1e-6). No gradients. Reserve two passes to measure selected patch and baseline on all eligible saved development rows, without subsequent retuning. Reserve three passes for final original/patch/random on seeds6–7. Budget log never exceeds50; failures counted.
Random control: seeded Gaussian unit directions, same layers/writers/topk/alpha; same targeted weight count, not necessarily identical nonzero BF16 change count nor norm. Freeze controls and patch before reading heldout.
One GPU process under tmux astra2, flock astra/gpu.lock; allocator cap 24 GiB, no writes outside astra on pod, no changes other tmux sessions. Heldout arrival monitored at 60-second cadence until 17:30 UTC; if producer incomplete then report partial snapshot explicitly. No claim about rollout success from teacher-forced results.
